Uma linha só não distingue três viaturas do mesmo modelo nem dois servidores homônimos — é o cargo, a unidade, o combustível que decidem qual é qual. A segunda linha é dado de apoio: ela não acompanha o accent da opção escolhida, senão a linha inteira grita e o rótulo perde o destaque. {% endcomment %} {% comment %} Documento vinculado: a lista NÃO é menu suspenso.

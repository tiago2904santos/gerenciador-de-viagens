Formulário avançado

{% comment %} As três variações do picker num painel só, cada uma no seu `form_block`. Lado a lado é como se compara: a de uma linha e as de duas dividem campo, caixa de escolhidos e comportamento — o que muda é só a opção da lista, e isso só fica evidente quando as três estão na mesma superfície. Painéis separados diziam o contrário: sugeriam três componentes. {% endcomment %} {% comment %} Com opções de verdade: um picker sem nada para buscar não prova que está funcionando — foi assim que ele passou por pronto estando morto. {% endcomment %} {% comment %} A variação de DUAS LINHAS. Uma linha só não distingue três viaturas do mesmo modelo nem dois servidores homônimos — é o cargo, a unidade, o combustível que decidem qual é qual. A segunda linha é dado de apoio: ela não acompanha o accent da opção escolhida, senão a linha inteira grita e o rótulo perde o destaque. {% endcomment %} {% comment %} Documento vinculado: a lista NÃO é menu suspenso. Os candidatos ficam à vista e o campo só os filtra — escolher um ofício é comparar rota, período e equipe de dois deles, e isso exige vê-los lado a lado. Na tela real quem monta os cartões é o script da página, a partir de uma busca no servidor; aqui eles são fixos, para o catálogo mostrar o componente cheio. {% endcomment %} {% comment %} Um controle só, que aceita as duas coisas: marcar um dia e fechar dá uma data; marcar dois dá o intervalo. O rótulo do botão é o valor. {% endcomment %} {% comment %} A forma mínima, que é como as telas reais devem usar: a seção busca os próprios dados e liga o próprio motor. {% endcomment %}

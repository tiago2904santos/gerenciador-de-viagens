UI Lab — Field Layout

Field Row — Primitivos

FR

Demonstração isolada de cada variante de Field Row: 1, 2, 3 e 4 colunas, mistura e textarea full width.

field-row--4 — Quatro colunas

Campos compactos de mesma largura. Ideal para dados curtos: placa, tipo, código, status.

field-row--3 — Três colunas

Trios de campos relacionados. Ideal para nome + CPF + telefone ou cargo + RG + status.

field-row--2 — Duas colunas

Pares de campos. Ideal para datas, valores, e-mail + telefone, origem + destino.

field-row--1 — Uma coluna (linha inteira)

Linha inteira. Ideal para textarea, justificativa, unidade e campos que merecem destaque.

Texto livre. Aparece no verso do ofício quando preenchido.

Mistura de rows na mesma Form Section

Linha 1 com 3 colunas, linha 2 com 4 colunas, linha 3 com 1 coluna (textarea).

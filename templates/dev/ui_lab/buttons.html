Buttons Lab

Taxonomia funcional de botoes

Cada botao tem uma funcao semantica. As classes base (btn-primary, btn-secondary, btn-danger) definem hierarquia visual. Os modificadores funcionais (btn--document-pdf, btn--remove, etc.) adicionam identidade de acao sem quebrar o base.

Document Actions

Acoes documentais com identidade propria

Cada formato de documento tem uma cor que cria identidade imediata: teal (#0e7c9e) para visualizar/preview, vermelho-documental (#b42318) para PDF, azul-arquivo (#1a5498) para DOCX, verde (#16805a) para download. Nao usar o mesmo cinza generico para todos.

Acoes documentais completas Document

Visualizar: teal — consulta neutra. PDF: vermelho-documental — identidade forte. DOCX: azul-arquivo — distinto do primary do sistema. Download: verde — acao positiva.

Destructive Actions

Excluir vs Remover

Excluir e uma acao destrutiva permanente — usa fill vermelho (btn-danger). Remover e uma remocao local e reversivel — usa outline danger (btn--remove) ou fantasma (btn--remove-inline). A diferenca visual comunica o grau de risco antes do clique.

Destrutivo forte — Excluir Perigo

btn-danger — fill vermelho, comunica perigo imediato. btn-danger btn--danger-strong — sombra mais intensa para acoes totalmente irreversiveis.

btn--remove-inline — texto danger sem borda (minimo visual, remocao em linha). btn--remove — outline danger (sem fill), mais explicito que inline, menos agressivo que btn-danger.

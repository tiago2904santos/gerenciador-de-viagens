Button Grammar

Gramática visual de botões

A vitrine abaixo mostra apenas os formatos reutilizáveis definidos para o sistema: pill, circular, acoplado a campo e footer action. As telas reais seguem esta base fase por fase.

Visão geral 4 formatos

Pill, circular, field action e footer

Pills concentram as ações principais e secundárias. Botões circulares ficam para listas e documentos. Field actions sempre acompanham o campo. Footer actions fazem parte estrutural do card.

Pill Buttons

Botões pill

Formato padrão para salvar, cadastrar, finalizar, avançar, voltar e cancelar. A régua visual é a mesma em todos os exemplos.

Ações principais Primary
Secundárias e navegação Secondary

Voltar e voltar para lista continuam distintos. No claro, o texto de voltar para lista ganhou mais contraste. No escuro, a combinação foi refeita para não parecer desabilitada.

Documental Buttons

Ações documentais

Ações compactas para fluxo documental. Visualizar ficou mais elegante, assinar virou primário, gerar assinatura e copiar link ficaram secundários, e PDF/DOCX mantêm identidade própria sem exagero.

Fluxo documental Docs
Exportação documental PDF / DOCX

PDF e DOCX continuam reconhecíveis, mas agora com presença visual mais contida e proporcional ao restante do sistema.

Circular Buttons

Botões circulares

Exclusivos para ações compactas em lista, card ou documento. Cada botão recebe apenas ícone, com aria-label e tooltip obrigatórios.

Operacional Buttons

Botões operacionais

Ações de ferramenta reutilizáveis para operações como calcular rota e diária. Os ícones já existem no sistema e seguem a mesma régua visual dos demais botões pill compactos.

Ferramentas Tools

Destructive Buttons

Ações destrutivas

Excluir e remover compartilham a mesma linguagem visual destrutiva. A diferença fica só no rótulo e no ícone.

Destrutivas Danger

Field Attached

Botões acoplados a input e select

O botão lateral é uma ação simples ao lado do campo. Ele alinha só com a linha do input ou select e mantém a mesma altura visual.

Footer Action

Botão de rodapé integrado ao card

O rodapé inteiro é a ação. A área inferior do card funciona como footer clicável, com borda superior, fundo próprio e hover em toda a faixa.

Adicionar destino

O footer toma o lugar do botão solto e faz a área inteira parecer parte do card.

Cadastrar item

Serve para adicionar trecho, viajante, diária ou anexo dentro de blocos repetíveis.

Adicionar anexo

Versão neutra do rodapé, integrada ao bloco sem parecer um botão solto no final do card.

States

Estados do botão

A mesma régua compacta aparece em normal, hover, active, focus, disabled e loading.

Normal

Estado base do sistema.

Hover

Hover mais leve e clicável.

Active

Pressão sutil e sem peso excessivo.

Focus

Mostra o focus ring do sistema.

Disabled

Estado sem interação.

Loading

Spinner via classe is-loading.

State Buttons

Botoes de estado

Familia premium para success, warning, danger e neutral. Padrao global reutilizavel para estados, toggles e controles segmentados. A linguagem visual segue o botao lateral de campo: fundo translucido, borda semantica, glow suave, dot de estado e foco acessivel.

Estados simples

Success, warning, danger e neutral compartilham a mesma gramatica.

Toggle binario

Mesmo padrao usado pelos estados de RG.

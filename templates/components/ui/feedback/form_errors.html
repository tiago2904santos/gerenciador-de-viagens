{% comment %} Resumo de erro de formulário inteiro — o padrão único do `HT-03`. Antes deste PR havia **quatro** padrões e este componente, que era o certo, tinha **zero** chamadores de produção: 18 templates reaproveitavam `field_error.html` para `form.non_field_errors`, `roteiros/includes/_roteiro_editor.html` escrevia `
` à mão (classe do Bootstrap legado, fora do design system) e o login usava um quarto, `auth-error`. **E ele jogava a mensagem fora.** A versão anterior sempre imprimia "Revise os campos destacados antes de continuar", mesmo quando o form tinha `non_field_errors` com informação de verdade — "As duas senhas não conferem", "Já existe viatura com esta placa nesta área". Trocar os 18 chamadores por ele como estava teria **perdido informação**, que é o oposto de padronizar. Params: - `form`: o formulário; o componente lê `form.non_field_errors` - `errors`: lista explícita, para `formset.non_form_errors` (formset não tem `non_field_errors`, e `formset.errors` é lista de dicts vazios — **verdadeira** mesmo sem erro nenhum, então não serve de guarda) **Dois ramos, e não um `default` entre os dois.** A primeira versão era `errors|default:form.non_field_errors`, e isso **estourava**: variável que aparece como *argumento de filtro* não cai no `string_if_invalid` como a variável principal — ela levanta `VariableDoesNotExist`, e o `{% include %}` propaga. Como os dois chamadores de formset passam `errors` **sem** `form`, as telas de diário de bordo e de efetivo teriam dado 500. Pego pelo teste, não pela leitura. Quem move o foco para cá é `fields-init.js`, procurando `[data-form-errors]`. Sem isso o resumo é anunciado só por `role="alert"`, e conteúdo já presente na carga da página não é anunciado de forma confiável por leitor de tela — que é exatamente o efeito descrito no enunciado do `HT-03`. {% endcomment %} {% if errors %} {% include "components/ui/feedback/alert.html" with variant="danger" data_hook="form-errors" focalizavel=True title="Não foi possível continuar" message=errors|join:" " only %} {% elif form.non_field_errors or form.errors %} {% include "components/ui/feedback/alert.html" with variant="danger" data_hook="form-errors" focalizavel=True title="Não foi possível continuar" message=form.non_field_errors|join:" "|default:"Revise os campos destacados antes de continuar." only %} {% endif %}
